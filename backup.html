📥 Restaurar backup

Se você possui um backup anterior, selecione o arquivo JSON para restaurar os dados armazenados nele.

⚠️ Importante sobre o backup

O arquivo contém os dados armazenados localmente pelo GrillCore neste dispositivo.

Recomendamos guardar uma cópia em outro local, como computador, pendrive ou armazenamento em nuvem.

Atenção: ao restaurar um backup, os dados das áreas presentes no arquivo serão substituídos pelos dados do backup.

Faça um backup atual antes de realizar uma restauração importante.
